# toml-lite

TOML 子集解析（表、标量、数组、内联表），只用 Python 标准库。

```
python3 -m tomllite.cli --text 'a = [1, 2, 3]'
python3 -m tomllite.cli --text 'a = 1\na = 2'
python3 -m unittest discover -s tests -v
```

## 口径（README 为准）

- **数组要按逗号切分并递归解析**：`a = [1, 2, 3]` 按口径是 `[1, 2, 3]`（整数列表），
  现在给字符串 `"1, 2, 3"`；数组里可以嵌套数组与内联表 `{x = 1}`。
- **重复键必须报错**：同一张表里同一个键出现两次要报
  「重复键 a（第 1 行与第 2 行）」，现在静默取最后一个值。
- 标量：双引号字符串（含 `\n`、`\"`、`\\` 转义）、整数（支持下划线与 `0x` 前缀）、浮点、布尔、
  日期时间按字符串原样保留。
- 错误要带行号与列号：缺 `=`、表头不闭合、非法转义、数组元素类型混杂都要报错并指出位置。
- 不变量：解析结果与标准库 `tomllib` 对同一份合法 TOML 的结果逐键一致（日期可归一成字符串）；
  同一输入重复解析结果相同；空输入返回空字典。
- 规模：10 MB 的 TOML 单遍解析，内存 O(输出结构)；不许用正则回溯去切数组。

## 现在的行为

- `parse_scalar` 对 `[...]` 只做 `text[1:-1]`：数组变成一个字符串（`"1, 2, 3"`），元素不解析。
- 重复键用 `table[key] = value` 覆盖：`a = 1` 后再 `a = 2` 得到 `{"a": 2}`。
- 报错都只有一句话，没有行号/列号；转义、下划线整数、`0x` 前缀都不支持。

## 计划新增的能力

```
--text 文本    用 \n 表示换行
--file 文件    从文件读
```

## 输出

```
{"a": [1, 2, 3]}
```
